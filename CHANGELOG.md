# Changelog

## 1.0.0 (2026-11-15)

The first release of KholaBangla Keyboard.

- Bangla typing with Avro Phonetic (dictionary suggestions, autocorrect) and the Probhat, Munir Optima,
  National (Jatiya), Bornona, Avro Easy and Khipro layouts.
- Works with both IBus and Fcitx5, and adds itself to the input sources on GNOME, KDE Plasma, Cinnamon,
  XFCE, MATE, Budgie, LXQt and Deepin.
- One-command installer for Ubuntu, Debian, Kali Linux, Fedora, openSUSE Tumbleweed, Arch Linux and their
  derivatives, on x86_64 and ARM64.
- New design that follows the system's light or dark theme.
- Package installation no longer fails when there is no desktop session (SSH, containers).

Based on the OpenBangla Keyboard 3.0.0 development version; see [AUTHORS.md](AUTHORS.md).
